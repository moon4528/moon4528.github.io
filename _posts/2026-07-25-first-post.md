안녕하세요.

오늘은 GitHub Pages를 이용해 개발 블로그를 만들었습니다.

## GitHub Pages란?

GitHub 저장소의 파일을 웹사이트로 배포할 수 있는 기능입니다.

## 블로그를 만든 이유

프로젝트를 진행하며 해결한 문제와 새롭게 공부한 내용을 기록하기 위해 만들었습니다.

## 앞으로 작성할 내용

- Spring Boot 개발 기록
- PostgreSQL 설계
- Redis 활용 방법
- Docker 배포
- AWS 서버 운영
- 프로젝트 트러블슈팅

앞으로 꾸준히 기록하겠습니다.
